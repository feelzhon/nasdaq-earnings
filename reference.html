2. 数据源对比

「市值前 1000」这个需求，关键在两点：① 能否拿到市值排序 ② 能否拿到财报日期。

数据源需要 Key市值数据财报日期免费额度稳定性
纳斯达克公开 API（api.nasdaq.com） 无需 有（screener 可按市值排序） 有（/calendar/earnings） 无明确限制 中（需 UA 请求头）
Financial Modeling Prep (FMP) 需要 有 有（含 EPS/营收） 250 次/天 高
Yahoo Finance（抓取） 无需 有 有 无明确限制 低（易封禁）
Finnhub 需要 部分 财报日历为付费端点 60 次/分 中

结论：纳斯达克公开 API 是最优解——免费、无需 Key，且能同时拿到「市值排序」和「财报日期」，两个需求一次满足；FMP 作为可选增强（补充 EPS/营收预期）。
